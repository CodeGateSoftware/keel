# Decision records

Short, dated records of decisions that outlive the code that implements them. Format:
**Context / Options / Decision / Consequences**, one decision per file, numbered in order,
citing the issue that asked the question. A decision here is a standing rule — it is changed
by writing a new record that supersedes it, never by quietly editing an old one.
