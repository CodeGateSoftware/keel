## Source 13 — "The Guaranteed Financial Freedom Roadmap"

> **Mostly out of scope** (like Source 11): personal-finance / wealth-building — budgeting, DTI,
> expense matrices, buffers, self-development, the LA/LE/LI freedom formula, index-fund investing.
> Not trading-agent mechanics. Captured: only the few bits that touch the agent.

### 13.1 Reinforcements (already captured — no new code)
- **Portfolio allocation by risk tier + "earn your right to risk."** Start ~**10% to speculation**,
  ramp gradually (e.g. 90/10 → 80/20 → 70/30) as skill/track-record grows. Reinforces the
  **speculation-cap / dedicated-portfolio** choice (§2.8, §10.7). For us this is a *funding* policy,
  not an agent parameter — the agent trades whatever the funded slice is.
- **DCA / "buy stocks like groceries, not perfume" (Graham)** — reinforces the DCA backbone (§10.8, §12.1).
- **Strike-rate/R:R sweet spot: ~55% win with ~1.2–1.5–2:1 R:R**; "traders fail chasing 100% win or
  10:1 swings." Restates the promotion floor (§4.5) — no change, just another confirmation.
- **Compounding** on retained equity — reinforces §4.7.

### 13.2 Noted-but-not-adopted
"Don't learn to trade for <25–60%/yr" — a personal motivation heuristic (same as §11.2), **not** an
agent target. Our targets come from the promotion gate (expectancy + R:R/win floors), not an
aspirational annual %.

three-freedoms (money/mobility/mind), book/tool promos. All personal-finance/lifestyle, none agent.
