## Source 11 — "The Best Way to Make Money" (business/wealth philosophy)

> **Out of scope for the trading agent.** This is about building a *positive-sum business*
> (newsletter → membership → course funnel, the "FAIR" formula) and personal-wealth compounding —
> not trading mechanics. Logged for completeness; almost nothing is agent-actionable.

### 11.1 Tiny reinforcements (already captured elsewhere — no new code)
- **"Trading grows money, it doesn't earn it — you need capital first."** Reinforces the
  **fund-with-losable-capital / speculation-cap** design choice (§2.8/§10.7). The agent operates on
  an already-funded portfolio; it is not an income source.
- **Compounding** on retained profits (7%+ example) — reinforces §4.7 (size on current equity).
- **Emotional mastery / long-term thinking / "master of risk"** — the agent is structurally immune
  by design (rules + rails); nothing new (cf. §4.10, §5.4).

### 11.2 Noted-but-not-adopted
"Don't bother trading for <25%/yr" is a personal motivation heuristic, not an agent parameter —
and it sits *above* our deliberately conservative posture. **Not adopted**; our targets stay set by
the promotion gate (expectancy + R:R≥1.5–2, §4.5), not by an aspirational annual-return number.

### 11.3 Discarded (no agent value) — i.e. the whole rest of the source
Positive-sum vs zero-sum framing, the FAIR (frequency×audience×income×result) formula, the
newsletter/membership/course funnel case study & conversion math, tax/lifestyle math, "knowledge→
income→equity" ordering, book/CTA promos. All business-building, none trading-agent.
